# Цены Каспи для страницы отбора

Публичные цены с kaspi.kz по списку товаров из `ids.json`. Раз в сутки (08:00 Алматы) GitHub Actions
запускает `prices.py` и обновляет `prices.json`; страница отбора читает этот файл и показывает свежие цены.

Обновить вручную: вкладка **Actions → «Обновить цены Каспи» → Run workflow**.
